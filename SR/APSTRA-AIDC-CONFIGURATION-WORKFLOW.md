## AIDC 三网配置差异对比

| 维度 | GPU Backend | Storage Backend | Frontend |
|------|-------------|-----------------|----------|
| Overlay 协议 | Pure IP Fabric（无 VXLAN） | IP Fabric 或 EVPN-VXLAN | EVPN-VXLAN |
| QoS 策略 | DCQCN（PFC + ECN）无损 | 可选无损 | 标准 Best-Effort |
| 负载均衡 | DLB / GLB / ALB | ECMP | ECMP |
| 拓扑结构 | Rail-optimized Clos | 标准 3-stage Clos | 标准 3/5-stage Clos |
| Configlet 需求 | 必须（QoS + LB） | 可选 | 通常不需要 |
| Buffer 分配 | Lossless 66% + Headroom 24% + Lossy 10% | 按需调整 | 默认 |
| 流量标记 | DSCP 011010（RoCEv2）+ 110000（CNP） | 按需 | 无特殊标记 |
