2. 功能需求

2.1 AIDC Dashboard

2.1.1 功能说明

AIDC Dashboard 是 AIDC Network App 的 Overview 功能模块，为数据中心 AI 网络场景提供统一的运维监控视图。Dashboard 采用 3×3 九宫格布局，涵盖以下 10 个功能单元：

序号功能单元面板位置优先级说明
1Dashboard 工具栏顶部P0视图切换、面板管理、全屏、导入导出，所有 App Dashboard 共享
2网络健康度评估R1-C1P0站点健康度评分环形图，含站点名称、场景类型、运行状态
3队列丢包 Top5R1-C2P0按 ECN 报文数降序排列的 Top5 设备端口
4Headroom Buffer 利用率趋势图R1-C3P1面积折线图，含阈值参考线
5设备资源统计R2-C1P0设备在线/离线/异常统计 + 设备类型分布条形图
6ECN 报文数 Top5R2-C2P0交换机/网卡双 Tab 切换，Top5 排名表
7网络拥塞趋势图R2-C3P1多线折线图，展示拥塞指标趋势
8资产负载排名 Top5R3-C1P1CPU/内存/温度三 Tab 切换，Top5 排名表
9告警汇总R3-C2P02×2 网格卡片，四级告警统计
10Events 事件流R3-C3P0告警事件列表，支持按严重程度筛选

面板布局矩阵：

行列 1列 2列 3
Row 1网络健康度评估队列丢包 Top5Headroom Buffer 趋势图
Row 2设备资源统计ECN 报文数 Top5网络拥塞趋势图
Row 3资产负载排名 Top5告警汇总Events

2.1.2 原型界面

① Dashboard 工具栏

┌──────────────────────────────────────────────────────────────┐
│ Views: [Default ▼]                    [+📄] [⊞] [⛶] [⋯]   │
└──────────────────────────────────────────────────────────────┘
  • Views 下拉框：Default / AmpCon Cluster / Device Health
  • ⋯ 更多菜单：设置为默认 / 复制 / 删除 / 导出JSON / 导出JPEG / 导入

② 网络健康度评估（R1-C1）：站点名称 + 场景类型 + 运行状态文字 + 健康度环形图（0-100）

③ 队列丢包 Top5（R1-C2）：排名/设备名/端口/ECN报文数 表格，5 行

④ Headroom Buffer 趋势图（R1-C3）：面积折线图，绿色趋势线 + 橙色虚线阈值线（75%），Y 轴 0%-100%

⑤ 设备资源统计（R2-C1）：环形图（在线蓝/离线红）+ 统计数字 + 设备类型水平条形图

⑥ ECN 报文数 Top5（R2-C2）：[交换机][网卡] Tab 切换，表格 5 行

⑦ 网络拥塞趋势图（R2-C3）：蓝/绿/橙三条指标线折线图，X 轴 00:00-24:00

⑧ 资产负载排名 Top5（R3-C1）：[CPU][内存][温度] Tab 切换，排名/设备名/IP/利用率进度条

⑨ 告警汇总（R3-C2）：2×2 网格，严重(红)/重要(橙)/一般(黄)/提示(蓝) 四张卡片

⑩ Events（R3-C3）：[All ▼] 筛选下拉 + 事件列表（圆点+时间+站点+描述）

2.1.4 列表字段

② 网络健康度评估

字段类型来源说明
站点名称文本Site.name如 "Frankfurt Data Center"
场景类型文本固定"数据中心场景"
运行状态文本计算≥90 健康(#10b981) / 70-89 一般(#f59e0b) / <70 异常(#ef4444)
健康度评分数值Site.health0-100，环形图展示

③ 队列丢包 Top5 / ⑥ ECN 报文数 Top5（交换机 Tab）

字段类型说明
排名/#数值1-5
设备名文本设备名称
端口文本端口标识，等宽字体
ECN 报文数数值千分位格式化

⑥ ECN 报文数 Top5（网卡 Tab）

字段类型说明
#数值1-5
设备名文本服务器名称
网卡名称文本如 mlx5_0，等宽字体
ECN 报文数数值千分位格式化

⑤ 设备资源统计

字段类型说明
设备总数数值Site.deviceCount
设备在线数数值在线设备数量
设备在线率百分比在线数/总数
设备离线数数值离线设备数量
异常设备数数值红色标识
设备类型分布条形图Spine(靛蓝)/Leaf(绿)/Border Leaf(琥珀)/Other(灰)

⑧ 资产负载排名 Top5

字段类型说明
排名数值1-5
设备名文本设备名称
IP文本管理 IP，等宽字体
当前利用率百分比+进度条≥80% 红色，≥60% 橙色，其余蓝色

⑨ 告警汇总

告警级别背景色数字颜色对应级别
严重告警红色浅底红色Critical
重要告警橙色浅底橙色Major
一般告警黄色浅底黄色Minor
提示告警蓝色浅底蓝色Warning/Info

⑩ Events 事件流

字段类型说明
严重程度指示圆点红=CRITICAL，橙=MAJOR，黄=MINOR
时间时间戳等宽字体，YYYY-MM-DD HH:mm:ss
站点文本事件来源站点
事件描述文本告警消息内容

2.1.5 异常与容错处理

异常场景处理方式
数据采集服务不可用面板显示"数据加载中"或上次缓存数据，不显示空白
站点无设备健康度显示 100，设备统计显示 0，Top5 表格显示"暂无数据"
告警服务不可用告警汇总显示 0，Events 显示"暂无事件"
单个面板渲染失败仅该面板显示错误提示，不影响其他面板
数据刷新超时保留上次数据，下次周期重试
筛选无匹配Events 显示"暂无匹配事件"

2.1.7 功能约束与边界

约束说明
工具栏为共享组件所有 App Dashboard（AIDC/IDC/Campus 等）使用同一工具栏，仅数据面板不同
Dashboard 画布全宽无 max-width 限制，自适应容器宽度
3×3 等宽网格每行 3 个面板，gap 16px，同行面板等高
面板卡片样式白色背景，1px 浅灰边框，8px 圆角，无阴影
标题栏与内容分离标题 12px font-semibold，底部分隔线
背景色#f0f2f5
Top5 固定 5 条不足时显示实际数量
Tab 切换默认值ECN 默认"交换机"，资产负载默认"CPU"，Events 默认"All"
数据刷新周期30 秒自动轮询
首屏加载≤ 2 秒（9 面板全部渲染）
浏览器兼容Chrome 90+ / Edge 90+ / Firefox 90+
最小宽度1200px，低于此水平滚动
