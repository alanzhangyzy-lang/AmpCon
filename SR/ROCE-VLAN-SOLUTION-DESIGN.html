6.1.1 系统分层架构

层级模块职责
展示层VLAN 业务开通 UI工单表单、向导流程、配置预览、下发进度、验证结果展示

6.1.2 核心数据模型

// VLAN 业务开通工单
interface VlanProvisioningOrder {
  orderId: string;                    // 工单ID，自动生成 VO-{yyyyMMdd}-{seq}
  orderName: string;                  // 工单名称
  fabricId: string;                   // 所属 Fabric ID
  podId?: string;                     // 所属 POD（可选）
  status: OrderStatus;                // 工单状态
  
  // 业务参数
  vlanId: number;                     // VLAN ID (2-4094)
  vlanName?: string;                  // VLAN 名称
  networkType: 'L2' | 'L3';          // 网络类型：纯二层 / 三层网关
  gatewayIpv4?: string;              // 三层网关 IPv4 地址（含掩码）
  gatewayIpv6?: string;              // 三层网关 IPv6 地址（含掩码）
  vni?: number;                       // VXLAN VNI（跨 Leaf 延伸时必填）
  vrfName?: string;                   // VRF 实例名（多租户隔离）
  
  // 接入配置
  accessMode: 'single' | 'mlag';     // 接入模式：单归 / MLAG 双归
  serverAddressMode: 'dhcp-dynamic' | 'dhcp-static' | 'manual';  // 服务器地址分配方式
  dhcpPoolStart?: string;             // DHCP 地址池起始
  dhcpPoolEnd?: string;               // DHCP 地址池结束
  
  // 高级配置
  mtu: number;                        // MTU，默认 9216
  arpProxy: boolean;                  // ARP 代理，默认开启
  arpDirectRouteAdvertise: boolean;   // ARP 直连路由通告
  arpAgingTime: number;               // ARP 老化时间（秒），默认 90
  
  // RoCE 增强配置
  roceEnabled: boolean;               // 是否开启 RoCE QoS
  roceQueue: number;                  // RoCE 流量队列号，默认 3
  cnpQueue: number;                   // CNP 报文队列号，默认 6
  pfcEnabled: boolean;                // PFC 开关
  ecnEnabled: boolean;                // ECN 开关
  ecnMinThresh: number;               // ECN 最小阈值
  ecnMaxThresh: number;               // ECN 最大阈值
  
  // 下发目标
  targetDevices: TargetDevice[];      // 目标设备列表
  
  // 审计
  createdBy: string;
  createdAt: string;
  updatedAt: string;
}

// 目标设备
interface TargetDevice {
  deviceId: string;
  deviceName: string;
  role: 'spine' | 'leaf';
  ports: TargetPort[];                // 下发端口列表
  mlagPeerId?: string;               // MLAG 对端设备 ID
}

// 目标端口
interface TargetPort {
  portName: string;                   // 端口名称 如 xe-1/1/3
  portType: 'uplink' | 'downlink';   // 上联/下联
  accessVlan?: number;                // Access VLAN
  trunkVlans?: number[];              // Trunk 允许 VLAN 列表
}

// 工单状态
type OrderStatus = 
  | 'draft'           // 草稿
  | 'pending_review'  // 待审核
  | 'validated'       // 校验通过
  | 'resource_locked' // 资源已锁定
  | 'deploying'       // 配置下发中
  | 'verifying'       // 验证中
  | 'completed'       // 开通完成
  | 'failed'          // 失败
  | 'rolled_back';    // 已回滚

6.2 业务开通主流程设计

6.2.1 端到端流程

1
工单创建
用户选择 Fabric/POD，填写 VLAN ID、网关、接入模式、RoCE 参数，选择目标设备和端口
↓
2
参数校验
前端实时校验：VLAN ID 范围(2-4094)、IP 格式、MTU 范围、端口冲突检测
后端深度校验：VLAN 是否已被占用、端口是否已分配、IP 是否冲突、VNI 是否重复
↓
3
资源预占
对 VLAN ID、端口、IP 地址、VNI 加分布式锁，设置 TTL=30min，超时自动释放
↓
4
配置编排
根据业务参数 + 设备角色(Spine/Leaf) + 设备厂商，生成设备级配置指令集
Leaf 下联口 VLAN 接入 + Access/Trunk 模式
Leaf VLAN-BD 映射 + SVI 网关 + EVPN 实例 + VNI 绑定
Spine/Leaf 互联口 RoCE QoS(PFC + ECN + WRED) — 仅 roceEnabled=true 时
MLAG 双归端口同步配置 — 仅 accessMode=mlag 时
↓
5
事务化下发
按设备分组，每台设备内按原子事务下发：
① 接入端口配置 → ② VLAN/BD 配置 → ③ EVPN/VNI 配置 → ④ 网关配置 → ⑤ QoS/RoCE 配置
每步下发后回读验证，单步失败触发该设备全量回滚
↓
6
业务验证
端口验证 端口 UP/DOWN 状态、VLAN 成员关系
配置验证 回读设备 running-config 与期望配置对比
转发验证 同 VLAN 内 Ping 连通性、跨 Leaf ARP 解析
策略验证 PFC/ECN 队列状态、QoS 策略生效确认
↓
7
开通完成
资源正式锁定，工单状态置为 completed，生成配置快照，记录审计日志

6.2.2 配置下发事务模型

下发阶段配置内容回读验证失败策略
Phase 1 接入端口 端口 switchport mode、native-vlan-id、trunk allowed-vlan 回读端口 VLAN 配置 回滚端口配置
Phase 2 VLAN/BD VLAN 创建、BD 绑定、VLAN-BD 映射 回读 VLAN 列表 删除 VLAN + 回滚 Phase 1
Phase 3 EVPN/VNI EVPN 实例创建、VNI 绑定、Route-Target 配置 回读 EVPN 实例 删除 EVPN 实例 + 回滚 Phase 1-2
Phase 4 网关 SVI 接口创建、IP 地址配置、VRF 绑定、ARP 代理 回读 SVI 接口 删除 SVI + 回滚 Phase 1-3
Phase 5 QoS/RoCE PFC Profile、ECN/WRED、Scheduler、Classifier 应用到端口 回读 QoS 策略 移除 QoS 策略 + 回滚 Phase 1-4
Phase 6 DHCP DHCP Server/Relay 配置、地址池、静态绑定 回读 DHCP 配置 删除 DHCP 配置 + 回滚 Phase 1-5
