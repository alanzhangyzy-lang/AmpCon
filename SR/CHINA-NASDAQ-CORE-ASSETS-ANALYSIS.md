# 中国"纳斯达克核心资产"深度分析报告

> 报告日期：2026年4月28日  
> 定位：寻找中国资本市场中具备长期成长性、政策支持、技术壁垒的"核心资产"——类比美国纳斯达克的科技成长股逻辑

---

## 一、宏观框架：为什么现在是寻找"中国纳斯达克资产"的关键窗口

### 1.1 政策驱动：十五五规划（2026-2030）的战略信号

十五五规划（2026-2030）相比十四五有几个显著升级：

- **AI + 制造**被列为核心战略，国家明确要求发展自主可控的智能芯片、边缘计算芯片，并升级"东数西算"工程
- **人形机器人**首次被列为优先发展产业，目标2026年商业化、2028年多行业普及
- **低空经济**从2024年首次写入政府工作报告，到十五五规划中升级为"战略性新兴产业集群"，预计2035年市场规模达3.5万亿元
- **商业航天**与低空经济并列，成为新增长极
- **绿色能源与新能源汽车**继续深化，从"规模竞争"转向"技术决胜"

### 1.2 国际形势：脱钩压力催生国产替代红利

- 美国持续收紧对华半导体出口管制（2025年1月起限制美国企业投资中国AI/半导体/量子技术）
- 中美贸易战使中国2025年贸易顺差首次突破1万亿美元，出口韧性超预期
- 外部压力倒逼国内"自主可控"加速落地，信创、半导体、AI基础设施国产替代成为确定性主线
- DeepSeek的崛起证明中国AI在算法效率上已具备全球竞争力，打破"中国只能跟随"的叙事

### 1.3 核心投资逻辑

**类比纳斯达克的选股标准：**
1. 处于政策重点支持的新兴赛道
2. 具备技术壁垒或生态护城河
3. 收入增速显著高于GDP增速
4. 在国内或全球细分市场具备领导地位
5. 战略清晰，有明确的商业化路径

## 五、风险提示

1. **地缘政治风险**：中美关系持续紧张可能导致额外制裁，影响半导体、AI等行业
2. **监管风险**：国内互联网/平台经济监管政策变化，影响AI大模型公司估值
3. **估值风险**：部分赛道（人形机器人、低空经济）短期炒作情绪浓厚，估值透支未来
4. **技术落地风险**：人形机器人、eVTOL等技术商业化进程可能慢于预期
5. **汇率风险**：人民币汇率波动影响出海企业盈利

## 六、核心结论

**中国"纳斯达克核心资产"的本质是：在政策强力支持下，具备全球竞争力的科技成长型企业。**

- 短期（1-6个月）：优先关注**AI算力基础设施**（光模块、AI芯片）和**人形机器人产业链**（减速器、传感器），催化剂明确，业绩兑现快
- 中期（6-12个月）：布局**低空经济**（无人机、eVTOL）和**半导体国产替代**，政策细则落地驱动
- 长期（1-3年）：持有**新能源汽车智能化**（比亚迪、宁德时代、地平线）和**AI大模型平台**（阿里、腾讯、百度），享受中国科技崛起的复利
