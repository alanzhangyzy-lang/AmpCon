## 2. 功能需求

### 2.1 Dashboard 面板分类体系

#### 2.1.1 功能说明

Dashboard 面板库采用 6 大分类组织所有可用面板。用户通过 "Add Panel" 按钮打开面板库, 按分类浏览并添加面板到当前 Dashboard 视图。

不同 App 的 Default View 预置不同面板组合, 但面板库对所有 App 共享。

#### 2.1.2 分类定义

| 序号 | 分类 | 英文标识 | 设计目的 | 适用场景 |
|------|------|----------|----------|----------|
| 1 | 概览与健康 | overview | 一眼看全局, 网络整体好不好 | Cloud DC + AIDC |
| 2 | 设备与资源 | device | 硬件有没有压力, 哪台设备异常 | Cloud DC + AIDC |
| 3 | 流量与性能 | traffic | 流量哪里有瓶颈, 带宽够不够 | Cloud DC + AIDC |
| 4 | 拥塞与无损 | congestion | 无损网络有没有问题(ECN/PFC/Buffer) | AIDC 专属 |
| 5 | 告警与事件 | alarm | 发生了什么, 需要关注什么 | Cloud DC + AIDC |
| 6 | 合规与保障 | compliance | 网络达不达标, 配置是否合规 | Cloud DC + AIDC |

## 5. 面板通用规格

### 5.1 面板卡片样式

| 属性 | 值 |
|------|-----|
| 背景色 | 白色 (#FFFFFF) |
| 边框 | 1px solid #E2E8F0 |
| 圆角 | 8px |
| 阴影 | 无 (Grafana 风格) |
| 标题栏 | 12px font-semibold, 底部分隔线 |
| Dashboard 背景 | #F0F2F5 (浅灰) |
| 网格间距 | 16px gap |
| 最小宽度 | 1200px, 低于此水平滚动 |

### 5.2 排名标识通用样式

| 排名 | 背景色 |
|------|--------|
| Top 1 | 红色 (#EF4444) |
| Top 2 | 橙色 (#F59E0B) |
| Top 3-5 | 灰色 (#9CA3AF) |

### 5.3 数据刷新

| 属性 | 值 |
|------|-----|
| 默认刷新周期 | 30 秒自动轮询 |
| 首屏加载 | <= 2 秒(所有面板渲染完成) |
| 数据缓存 | 采集服务不可用时展示上次缓存数据, 不显示空白 |

### 5.4 Top N 通用规格

| 属性 | 值 |
|------|-----|
| 默认 N 值 | 5 |
| 可选 N 值 | 5 / 10 / 15 / 20 |
| 不足 N 条时 | 显示实际数量 |
| 无数据时 | 显示"暂无数据" |

## 6. 异常与容错处理

| 异常场景 | 处理方式 |
|----------|----------|
| 数据采集服务不可用 | 面板显示"数据加载中"或上次缓存数据 |
| 站点无设备 | 健康度显示 100, 设备统计显示 0, Top5 显示"暂无数据" |
| 告警服务不可用 | 告警汇总显示 0, Events 显示"暂无事件" |
| 单个面板渲染失败 | 仅该面板显示错误提示, 不影响其他面板 |
| 数据刷新超时 | 保留上次数据, 下次周期重试 |
| AIDC 面板在 Cloud DC App 中 | 拥塞与无损分类不显示在面板库中 |
