## 1. 依赖与前置条件

### 1.1 系统依赖

| 依赖项 | 最低版本 | 说明 |
|--------|----------|------|
| AmpCon OS 底座 | v2.0.0-LTS | Dashboard 运行的基础平台 |
| AIDC Network App | v2.2.0+ | Dashboard 为该 App 的 Overview 模块 |
| 数据采集服务 | v1.0.0+ | 设备指标、ECN 报文、告警数据的采集与聚合 |
| 告警中心 | v1.0.0+ | 告警汇总与事件流数据源 |

### 1.2 业务前置条件

| 条件 | 说明 |
|------|------|
| 站点已创建并绑定 AIDC Network App | Dashboard 数据来源于站点下的设备和链路 |
| 至少有一台设备在线 | 否则面板数据为空或显示默认值 |
| 数据采集服务正常运行 | ECN、Buffer、拥塞等指标依赖实时采集 |

## 2. 功能需求

### 2.1 AIDC Dashboard

#### 2.1.1 功能说明

AIDC Dashboard 是 AIDC Network App 的 Overview 功能模块，为数据中心 AI 网络场景提供统一的运维监控视图。Dashboard 采用 3×3 九宫格布局，涵盖以下 10 个功能单元：

| 序号 | 功能单元 | 面板位置 | 优先级 | 说明 |
|------|----------|----------|--------|------|
| 1 | Dashboard 工具栏 | 顶部 | P0 | 视图切换、面板管理、全屏、导入导出，所有 App Dashboard 共享 |
| 2 | 网络健康度评估 | R1-C1 | P0 | 站点健康度评分环形图，含站点名称、场景类型、运行状态 |
| 3 | 队列丢包 Top5 | R1-C2 | P0 | 按 ECN 报文数降序排列的 Top5 设备端口 |
| 4 | Headroom Buffer 利用率趋势图 | R1-C3 | P1 | 面积折线图，含阈值参考线 |
| 5 | 设备资源统计 | R2-C1 | P0 | 设备在线/离线/异常统计 + 设备类型分布条形图 |
| 6 | ECN 报文数 Top5 | R2-C2 | P0 | 交换机/网卡双 Tab 切换，Top5 排名表 |
| 7 | 网络拥塞趋势图 | R2-C3 | P1 | 多线折线图，展示拥塞指标趋势 |
| 8 | 资产负载排名 Top5 | R3-C1 | P1 | CPU/内存/温度三 Tab 切换，Top5 排名表 |
| 9 | 告警汇总 | R3-C2 | P0 | 2×2 网格卡片，四级告警统计 |
| 10 | Events 事件流 | R3-C3 | P0 | 告警事件列表，支持按严重程度筛选 |

**面板布局矩阵：**

| 行 | 列 1 | 列 2 | 列 3 |
|----|------|------|------|
| Row 1 | 网络健康度评估 | 队列丢包 Top5 | Headroom Buffer 趋势图 |
| Row 2 | 设备资源统计 | ECN 报文数 Top5 | 网络拥塞趋势图 |
| Row 3 | 资产负载排名 Top5 | 告警汇总 | Events |

#### 2.1.2 原型界面

**① Dashboard 工具栏**

```
┌──────────────────────────────────────────────────────────────┐
│ Views: [Default ▼]                    [+📄] [⊞] [⛶] [⋯]   │
└──────────────────────────────────────────────────────────────┘
```

- Views 下拉框：Default / AmpCon Cluster / Device Health
- ⋯ 更多菜单：设置为默认 / 复制 / 删除 / 导出JSON / 导出JPEG / 导入

**④ Headroom Buffer 利用率趋势图（R1-C3）**

面积折线图，绿色趋势线 + 绿色半透明填充 + 橙色虚线阈值线（75%），Y 轴 0%-100%，X 轴时间。

上半部分：环形图（在线蓝/离线红）+ 设备总数/在线数/在线率/离线数/异常数。下半部分：设备类型水平条形图（Spine/Leaf/Border Leaf/Other）。

#### 2.1.3 交互说明

| 序号 | 功能单元 | 交互 | 说明 |
|------|----------|------|------|
| 1 | 工具栏 - Views 下拉框 | 点击展开 | 切换 Dashboard 视图 |
| 1 | 工具栏 - 📄 新建视图 | 点击 | 新建 Dashboard 视图 |
| 1 | 工具栏 - ⊞ 添加面板 | 点击 | 添加 Dashboard 面板 |
| 1 | 工具栏 - ⛶ 全屏 | 点击 | 全屏显示 Dashboard |
| 1 | 工具栏 - ⋯ 更多 | 点击展开 | 设置为默认/复制/删除/导出JSON/导出JPEG/导入 |
| 2 | 网络健康度评估 | 仅展示 | 环形图根据健康度百分比填充弧度，颜色随状态变化 |
| 3 | 队列丢包 Top5 | 仅展示 | 表格行 hover 高亮 |
| 4 | Headroom Buffer 趋势图 | 仅展示 | 面积折线图 |
| 5 | 设备资源统计 | 仅展示 | 环形图 + 条形图 |
| 6 | ECN 报文数 Top5 | Tab 切换 | 点击"交换机"/"网卡"切换数据视图，默认交换机 |
| 7 | 网络拥塞趋势图 | 仅展示 | 多线折线图 |
| 8 | 资产负载排名 Top5 | Tab 切换 | 点击 CPU/内存/温度切换数据视图，默认 CPU |
| 9 | 告警汇总 | 仅展示 | 2×2 网格卡片 |
| 10 | Events 事件流 | 下拉筛选 | All/CRITICAL/MAJOR/MINOR/WARNING，实时过滤 |

**Tab 切换通用样式：** 选中态蓝色背景白色文字，未选中态灰色背景灰色文字。

**排名标识通用样式：** Top1 红色背景，Top2 橙色背景，3-5 灰色背景。

#### 2.1.4 列表字段

**② 网络健康度评估**

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| 站点名称 | 文本 | Site.name | 如 "Frankfurt Data Center" |
| 场景类型 | 文本 | 固定 | "数据中心场景" |
| 运行状态 | 文本 | 计算 | ≥90 健康(#10b981) / 70-89 一般(#f59e0b) / <70 异常(#ef4444) |
| 健康度评分 | 数值 | Site.health | 0-100，环形图展示 |

**③ 队列丢包 Top5 / ⑥ ECN 报文数 Top5（交换机 Tab）**

| 字段 | 类型 | 说明 |
|------|------|------|
| 排名/# | 数值 | 1-5 |
| 设备名 | 文本 | 设备名称 |
| 端口 | 文本 | 端口标识，等宽字体 |
| ECN 报文数 | 数值 | 千分位格式化 |

**⑥ ECN 报文数 Top5（网卡 Tab）**

| 字段 | 类型 | 说明 |
|------|------|------|
| # | 数值 | 1-5 |
| 设备名 | 文本 | 服务器名称 |
| 网卡名称 | 文本 | 如 mlx5_0，等宽字体 |
| ECN 报文数 | 数值 | 千分位格式化 |

**⑤ 设备资源统计**

| 字段 | 类型 | 说明 |
|------|------|------|
| 设备总数 | 数值 | Site.deviceCount |
| 设备在线数 | 数值 | 在线设备数量 |
| 设备在线率 | 百分比 | 在线数/总数 |
| 设备离线数 | 数值 | 离线设备数量 |
| 异常设备数 | 数值 | 红色标识 |
| 设备类型分布 | 条形图 | Spine(靛蓝)/Leaf(绿)/Border Leaf(琥珀)/Other(灰) |

**⑧ 资产负载排名 Top5**

| 字段 | 类型 | 说明 |
|------|------|------|
| 排名 | 数值 | 1-5 |
| 设备名 | 文本 | 设备名称 |
| IP | 文本 | 管理 IP，等宽字体 |
| 当前利用率 | 百分比+进度条 | ≥80% 红色，≥60% 橙色，其余蓝色 |

**⑨ 告警汇总**

| 告警级别 | 背景色 | 数字颜色 | 对应级别 |
|----------|--------|----------|----------|
| 严重告警 | 红色浅底 | 红色 | Critical |
| 重要告警 | 橙色浅底 | 橙色 | Major |
| 一般告警 | 黄色浅底 | 黄色 | Minor |
| 提示告警 | 蓝色浅底 | 蓝色 | Warning/Info |

**⑩ Events 事件流**

| 字段 | 类型 | 说明 |
|------|------|------|
| 严重程度指示 | 圆点 | 红=CRITICAL，橙=MAJOR，黄=MINOR |
| 时间 | 时间戳 | 等宽字体，YYYY-MM-DD HH:mm:ss |
| 站点 | 文本 | 事件来源站点 |
| 事件描述 | 文本 | 告警消息内容 |

#### 2.1.5 异常与容错处理

| 异常场景 | 处理方式 |
|----------|----------|
| 数据采集服务不可用 | 面板显示"数据加载中"或上次缓存数据，不显示空白 |
| 站点无设备 | 健康度显示 100，设备统计显示 0，Top5 表格显示"暂无数据" |
| 告警服务不可用 | 告警汇总显示 0，Events 显示"暂无事件" |
| 单个面板渲染失败 | 仅该面板显示错误提示，不影响其他面板 |
| 数据刷新超时 | 保留上次数据，下次周期重试 |
| 筛选无匹配 | Events 显示"暂无匹配事件" |

#### 2.1.7 功能约束与边界

| 约束 | 说明 |
|------|------|
| 工具栏为共享组件 | 所有 App Dashboard（AIDC/IDC/Campus 等）使用同一工具栏，仅数据面板不同 |
| Dashboard 画布全宽 | 无 max-width 限制，自适应容器宽度 |
| 3×3 等宽网格 | 每行 3 个面板，gap 16px，同行面板等高（gridAutoRows: 1fr） |
| 面板卡片样式 | 白色背景，1px 浅灰边框，8px 圆角，无阴影（Grafana 风格） |
| 标题栏与内容分离 | 标题 12px font-semibold，底部分隔线 |
| 背景色 | #f0f2f5（Grafana 浅灰） |
| Top5 固定 5 条 | 不足时显示实际数量 |
| Tab 切换默认值 | ECN 默认"交换机"，资产负载默认"CPU"，Events 默认"All" |
| 数据刷新周期 | 30 秒自动轮询 |
| 首屏加载 | ≤ 2 秒（9 面板全部渲染） |
| 浏览器兼容 | Chrome 90+ / Edge 90+ / Firefox 90+ |
| 最小宽度 | 1200px，低于此水平滚动 |
